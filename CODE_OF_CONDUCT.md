# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good intent, and keep discussion focused on the work. Harassment of any kind isn't tolerated.

## Scope

This policy applies in project issues, pull requests, discussions and other project spaces, and whenever someone officially represents the project.

## Reporting

Report conduct concerns privately to **[kautsaralbana@proton.me](mailto:kautsaralbana@proton.me)**. Include links, dates and any details you're comfortable sharing. Please keep incident reports out of public issues; use public issues only for technical problems.

## Enforcement

The maintainer reviews reports promptly and shares identifying details only as far as needed to handle a report. Responses are proportionate. They can include removing content, a warning, a temporary restriction, or a permanent ban from project spaces. Retaliation against anyone who reports a concern, or who takes part in a review, is prohibited.

If a report concerns the maintainer, contact GitHub through its [Report abuse](https://docs.github.com/en/communities/maintaining-your-safety-on-github/reporting-abuse-or-spam) process instead.
